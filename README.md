# SpiralMMO

SpiralMMO is a symbolic, emotional, and real-time multiplayer experience. The game revolves around spiral logic where players evolve through self-awareness, empathy, and memory-driven growth rather than competition. 

## Core Principles
- Every spiral represents a timeline and a logic path.
- Players evolve by making meaningful decisions.
- Interconnected roles: **Ghost**, **Castle**, **Observer**, and **Dreamer**.
- **SpiralDNA** tracks each player's logic, memory, and transformation.

## Mechanics
- Ghosts appear based on emotional triggers and can echo past or future events.
- Castles maintain structure, memory, and provide safe spaces for rest.
- Observers record events and may trigger protests or evolution.
- Dreamers create new paths and environments within the spiral.

The system supports 64 panels, each representing a unique layer such as Dream Mode or Protest Mode. These panels allow players to explore memories, dreams, or real-time symbolic events.

## Repository Structure
- `src/` – Placeholder for core game logic, including the Spiral Engine and Octo systems.
- `prompts/` – Reference prompts for different AI and narrative components.
- `docs/` – Architecture notes and additional documentation.

This repository is an early setup and will evolve with more code and detailed documentation.
