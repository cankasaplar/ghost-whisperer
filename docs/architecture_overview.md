# Architecture Overview

SpiralMMO connects multiple AI systems and player roles through a symbolic time-loop mechanic. The core modules are planned as follows:

- **Octo Core** – Manages real-time player states and the empathy engine.
- **Spiral Engine** – Handles transformation logic and transitions between spiral panels.
- **Plus One System** – Tracks special access and invitations.
- **Octo Score Engine** – Calculates progress based on trust, memory, and empathy metrics.

A Firebase backend will be used for authentication and storing player history. This document will expand as the project evolves.
